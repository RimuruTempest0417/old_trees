# v0.12.1 — 介面措辭修正：不再出現「作業」字眼

使用者反映：化學視角頁面的「本頁沒有的東西（**作業要求的界線，先說清楚**）」這種寫法會讓老師誤會，
要求刪掉。這一版把所有把網站寫成「作業」的措辭清掉，並加測試鎖住，之後不會再冒出來。

## 改了什麼（只動文字，不動資料與功能）

| 位置 | 改動前 | 改動後 |
| --- | --- | --- |
| 化學視角頁首說明 | 「**作業要求 F**：針對『為什麼要保育、澳門的分佈、保育條件、歷史關聯』挑一點做化學視角補充。」 | 「這一頁把澳門官方的**空氣監測與降雨酸鹼度**數據，和本站的古樹資料放在一起看……每一項數字都標明來源；官方沒有公開的，就明說沒有。」 |
| 「本頁沒有的東西」卡標題 | 本頁沒有的東西（**作業要求的界線，先說清楚**） | 本頁沒有的東西 |
| 同卡第一項說明 | 「**作業要求提到**『市區及郊區土壤理化特性』」 | 「市區與郊區的土壤理化特性，公開資料只有官方報告的敘述段落與學術研究……」 |
| 監測頁的方法說明 | 「**作業提供的**官方名錄值視為較早的官方版本」 | 「官方名錄值視為較早的官方版本」 |
| 程式註解 | 「化學視角（#/chemistry）—— **作業要求 F** 的網站化呈現」 | 「化學視角（#/chemistry）—— 官方環境數據與化學機制的呈現」 |

**誠實的內容一律保留**：缺口照樣寫明（沒有官方逐點土壤理化與礦物成分數據、沒有實地採樣）、
數值照樣不換算不內插不平均、區域背景≠單株實測、相關不等於因果——只是不再用「作業要求」當理由。

RED→GREEN 驗證：對舊版檔案（`git show HEAD:public/js/chemistry.js`）執行同一段掃描邏輯會命中 4 行，
代表這條守門測試真的抓得到，不是空轉。
