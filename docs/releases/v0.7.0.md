# v0.7.0 — 列印：每株古樹一張 A4 檔案卡、實地考察單、路綫資料冊

## 這一版做了什麼

新增第八個分頁「列印」，把資料庫裡的資料變成**可以帶去現場的紙本**。三種模式：

| 模式 | 產出 | 內容 |
| --- | --- | --- |
| 古樹檔案卡 | 1 株 1 頁 A4 | 官方照片、13 項基本資料（編號／市政署名錄編號／樹種／學名／堂區／地點／座標與精度／樹齡／樹高／胸徑／冠幅／健康／分級）、官方形態描述、**現場查核清單**、指向線上詳情的二維碼 |
| 實地考察單 | 1 頁 A4 | 可帶入某株基本資料或完全空白；現場量測表格（日期、人員、胸徑、樹高、冠幅、健康、分級）、樹體與環境檢查勾選清單、素描區、記錄說明（含「不會覆寫官方名錄」與立即危險通報提醒） |
| 路綫資料冊 | 封面 ＋ 每站 1 頁 | 封面：路綫名、摘要、統計、**站點示意圖（含比例尺與指北針）**、二維碼；站頁：站序、座標、該站最多 6 株清單、觀察重點 |

入口：導覽列「列印」分頁；地圖單株詳情面板多了「A4 檔案卡」；路綫詳情多了「列印路綫資料冊」。
深連結：`#/card?tree=66`、`#/card?mode=form&tree=66`、`#/card?mode=book&route=<路綫代碼>`。
按「列印／存成 PDF」後在列印對話框選「另存為 PDF」即可得到 A4 PDF（建議勾「背景圖形」以保留色塊）。

## 實作要點

- **不補造資料**：官方沒有的值（胸徑 658 株全缺、冠幅只有 67/658）一律顯示「官方未提供」，並自動變成現場實測項目。
- **現場查核清單由資料推導**：健康為「需關注／瀕危」→ 查枯枝與腐朽；已分級 → 查保護設施；缺胸徑／冠幅 → 實測；樹齡 ≥100 年 → 查土壤壓實與排水；座標非官方 → GPS 校正；官方無照片 → 補拍。每一項都附「為什麼查」。
- **二維碼沿用 QR 碼分頁的編碼器**（qrcode-generator，MIT），不重複造輪子；檔案卡的碼指向詳情頁、考察單的碼指向該株的線上紀錄表——兩者是**不同**的碼，測試會比對兩者不可混用。
- **路綫示意圖不用地圖磚**：列印時外部圖磚經常缺圖或變空白，因此改用站點座標自行繪製 SVG（依緯度修正經度比例、含約略比例尺與指北針，並標明「示意圖，非等比地圖」）。
- **A4 邊界自己管**：`@page { size: A4; margin: 0 }` 搭配頁面自身 `padding: 12mm`，避免瀏覽器邊界與頁面留白疊加。
- 每次修改都更新本文件（Google Docs 專案文件同步）。

## 這一版踩到的坑（都補了測試）

1. **路綫資料冊只剩封面**：`/api/route` 的回傳是 `{route, statistics, stops, ...}`，我一開始只把 `data.route` 傳進繪製函式，所有停靠站當場消失。修法：整包傳入，並讓繪製函式同時容忍兩種形狀；另加一項測試明確記錄「只傳 meta 會退化成只有封面」。
2. **列印時橫幅佔掉第一頁**：示範模式橫幅是 `main` 底下 prepend 的 `.notice`，不在頁首裡，原本的列印 CSS 沒擋到，導致 PDF 第一頁是橫幅、卡片被擠到第二頁還多一張空白頁。修法：列印時只留 `#view-card` 裡的 `.card-sheet-wrap`（`body > *:not(main)`、`main > *:not(section.view)`、`#view-card > *:not(.card-sheet-wrap)`），並用真實 PDF 複驗頁數。
3. **測試自己的錯**：斷言寫成 `fieldUrl.includes('field=66')`，但網址結構是「模式放路徑、編號放查詢參數」（`#/field?tree=66`），程式沒錯、斷言錯，修正為比對 `#/field?tree=66` 結尾。
4. **右半邊站名超出紙面**：路綫示意圖的站名一律往右寫，位於圖右側的站名會畫到框外被裁掉 → 依站點位置改為向左、靠右對齊，並加測試守住。
5. **三種模式的欄位同時出現**：`.field` 是 `display:flex`，會蓋掉瀏覽器預設的 `[hidden]{display:none}` → 在列印樣式強制隱藏未選取的欄位（看截圖才發現的）。
6. 這台機器的無頭 Chrome 有時傾印完不會自己結束 → 檢查腳本改用「逾時即終止並取回已輸出內容」的方式，避免整批驗證卡死。
