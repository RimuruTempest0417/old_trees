# v0.8.0 — 離線 PWA：沒網路也能開，還能安裝到手機主畫面

## 一、做了什麼

| 能力 | 說明 |
| --- | --- |
| **離線開啟** | 第一次連線就把整個介面（HTML／CSS／12 個前端模組／vendor／圖示）存到本機。之後完全斷網仍可開啟、切換分頁。 |
| **資料快取** | `/api/*` 走 stale-while-revalidate：先顯示上次的結果，連上網路後自動更新。斷網時統計與清單照樣看得到。 |
| **照片與地圖** | 古樹照片與**使用者實際看過**的地圖圖磚採 cache-first，並限制數量（照片 150、圖磚 200）。**不主動批量下載**，遵守 OpenStreetMap 圖磚政策。 |
| **可安裝** | `manifest.webmanifest` 提供 192／512／maskable 圖示與三個長按捷徑（地圖／列印／考察），支援「加入主畫面」以獨立視窗開啟。 |
| **狀態看得見** | 頁首多一顆可點的徽章：離線可用／離線準備中／離線模式／有新版本；點開可看快取數量、清除離線快取、安裝到主畫面。 |
| **離線頁** | 首次離線且該頁沒快取過時，顯示自製的 `offline.html`（沿用同一套深淺色變數），而不是瀏覽器的恐龍頁。 |

## 二、關鍵設計（為什麼這樣做）

1. **預載清單不手寫**：`scripts/build-sw.mjs` 掃描實際檔案產生 `public/sw.js` 的預載清單，並同步快取版本為 `lib/repo.js` 的 `API_VERSION`。
   少列一個檔案 → 離線時某分頁白畫面；多列一個不存在的檔案 → `install` 失敗，等於完全沒有離線能力。兩者都在 `tests/pwa.test.js` 守住（重跑產生器必須無差異＋逐項以 HTTP 確認 200）。
2. **快取分三層**：`mht-shell`（介面，版本化）、`mht-data`（API 回應）、`mht-media`（照片／圖磚，有上限並自動修剪）。啟用新版本時清掉舊的 `mht-*`，不會把使用者的裝置塞滿。
3. **只處理 GET**：`POST /api/field-records` 直接進網路。離線時前端照既有設計暫存在瀏覽器，並在畫面明示。
4. **`/api/health` 不快取**：診斷資訊若被快取，會出現「明明升級了卻一直說要升級」這種假故障。
5. **離線指示不只看 `navigator.onLine`**：伺服器掛掉、被網路攔截時 `navigator.onLine` 仍是 true。
   因此 `api.js` 會把每次請求的實際結果用 `app:netissue` 事件回報，狀態改為「裝置有網路但連不上伺服器」也要顯示離線，並說明「顯示的是快取資料」。

## 四、已知限制（誠實說明）

- **離線地圖只有看過的區域**：圖磚只快取使用者實際瀏覽過的（上限 200 張），沒有全澳離線圖磚包（那會違反 OSM 政策且體積過大）。
- **首次就是離線狀態**：瀏覽器從未連上過本站時，service worker 還沒安裝，會看到 `offline.html`。用過一次之後才有離線能力。
- **手機主畫面圖示以 Chrome／Android 最完整**；iOS Safari 用 `apple-touch-icon`，`shortcuts` 不支援。
- 版本更新後需要重新載入一次（頁首會出現「有新版本」徽章可一鍵重新載入）。
