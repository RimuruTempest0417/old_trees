# v1.0.4 — 實地考察紀錄單：現場量測與觀察的填寫空間放大

你回報「現場量測與觀察的填寫空間不足」。把印出來的那張紙量過之後，原因很清楚：
**填寫格只有約 13mm × 7.5mm**——手寫數字根本寫不下，而紙的下方還有約 70mm 空白沒用到。

## 改什麼

| 項目 | 改前 | 改後 |
|---|---|---|
| 量測表的左欄寬 | 60mm | **95mm** |
| 填寫格寬 | 約 13mm | **25.6mm** |
| 填寫格高 | 7.5mm | **13.0mm**（約可寫兩行手寫字） |
| 欄寬分配 | 瀏覽器自動（標籤欄佔 30%） | 固定：標籤 23%／填寫格 27% |
| 標籤字級 | 9pt | 8.5pt（長標籤少換一行） |

換算下來填寫格的面積是原本的 **約 3.5 倍**（13×7.5mm → 25.6×13mm），
而「古樹編號／樹種／堂區／座標」那張小表與右欄的勾選、照片、素描都維持原樣。
