資料來源

  • 樹木資料：澳門市政署《古樹名木保護名錄》（整理檔 古樹.csv，658 筆）
  • 逐株座標、冠幅、胸徑、健康與分級、形態描述、古樹照片：市政署「澳門自然網」古樹名木官方資料（658 筆）
  • 物種相片：Wikimedia Commons（自由授權，各筆標示作者與授權）
  • 地圖底圖：© OpenStreetMap 貢獻者
  • 法規：第 11/2013 號法律《文化遺產保護法》及歷次《古樹名木保護名錄》行政長官批示

技術架構

  • 資料庫：Supabase（PostgreSQL），Row Level Security 僅開放匿名讀取
  • 後端：Vercel Serverless Functions（/api/*）
  • 前端：原生 JavaScript ＋ Leaflet ＋ Chart.js（第三方函式庫已內附，不依賴 CDN）
  • 分析：最小平方法／非線性擬合、ANOVA、卡方檢定、存續預測模型

使用提醒

  • 古樹座標、冠幅、胸徑、描述與照片為市政署「澳門自然網」公布資料；同一座標的多株樹以極小半徑展開，實地尋樹請以現場標牌為準。
  • 路綫為演算法建議，請依現場路況、開放時間與天氣調整。
  • 觀賞古樹請勿攀爬、刻字、採果或踩踏樹根區。

綜合研究—澳門古樹｜資訊任務：古樹保育網頁（相片、地圖查詢、路綫推薦、保育科普）
