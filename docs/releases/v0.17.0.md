# v0.17.0 — App 圖示美化 ＋ 程式碼與文件整理

這一版沒有新功能，做的是兩件「讓專案站得住」的事：把主畫面圖示從手工產物變成可重現的產出，
以及把累積下來的冗餘程式碼、文件與誤入版控的檔案清掉。

## 一、App 圖示（iPhone／Android 加入主畫面看到的那一個）

原本的圖示是舊版手工流程留下的產物：一張從卡通樹背景裁出來的點陣圖，加上兩行小字。
在 180 px 的主畫面上，字看不清、樹是模糊的，而且**沒有任何可重現的來源**——換一台機器就做不出同一張圖。

- **單一來源**：`public/icons/icon.svg`——深綠底、老樹剪影（有起伏的樹冠、分叉的樹幹、根盤接地陰影）、
  外圍一道金色細環代表《古樹名錄》的受保護印記。沒有文字（小尺寸下文字只會變成污點）。
- **產生器**：`npm run build:icons`（`scripts/build-icons.mjs`）。作法是用無頭 Chrome 把 SVG 以
  1024×1024 渲染成母圖，再用 macOS 內建 `sips` 縮成 180／192／512；**不引入任何 npm 相依**
  （這台機器沒有 rsvg／cairosvg，Chrome 是唯一穩定可用的點陣器；SVG 用本機 http 提供，
  因 `file://` 的 SVG 截圖在此機器會間歇性卡住）。
- **三個尺寸各有用途**：`apple-touch-icon.png` 180（iOS **不讀 manifest**，只認這個檔名）、
  `icon-192.png`（Android／桌面安裝提示）、`icon-512.png`（安裝與啟動畫面）。
- **刪掉一張多餘的圖**：`icon-maskable-512.png` 原本與 `icon-512.png` 內容相同。
  Android 的圓形裁切要求內容落在中央 80% 安全區內，本站構圖（最外緣＝金環半徑 358／1024）本來就符合，
  因此 manifest 改標 `any maskable`，少一個檔案也少一個要同步的地方。
- **favicon** 改用同一份 SVG（原本是 🌳 emoji 的 data URL），並保留 PNG 後備。
- **忘了重跑產生器會被測到**：`build-icons.mjs --check` 比對 SVG 雜湊與 `icon-meta.json`，
  `tests/pwa.test.js` 另守住「外環不得超出安全區」與「apple-touch-icon 必須是 180×180」。

圖示迭代過程用視覺檢查逐版修正了兩個問題：多個圓各自套漸層會變成一顆顆「泡泡」（改用
`userSpaceOnUse` 讓整片樹冠共用一道光）、亮面圓超出樹冠輪廓會變成外凸的亮塊（改用 `clipPath` 裁在剪影內）。

## 二、刪除冗餘：一整包誤入版控的瀏覽器設定檔

`prof-微細懸浮粒子/`——**484 個檔案、7.7 MB** 的無頭 Chrome 設定檔（含瀏覽器擴充功能的程式碼）被 commit 進版控。
它不會讓任何測試紅燈，只會讓 clone 變慢、讓 `node --check` 掃到不屬於本專案的檔案。
已從版控與磁碟移除，並在 `.gitignore` 加上 `prof-*/` 防止再長回來。

## 三、刪除被取代的驗證腳本（4 支）

| 刪除 | 取代者 | 原因 |
| --- | --- | --- |
| `verify-ui.sh` | `ui-audit.sh` | 舊版只抓 5 個分頁的 DOM；新版量 12 分頁 × 5 寬度 × 深淺色共 120 項，含溢出、觸控目標、字級 |
| `dom-grep.sh` | `cdp-check.mjs` | `--dump-dom` 配 `--virtual-time-budget` 會在第一次繪製就輸出，非同步狀態還沒定案就當成結果 |
| `shot.sh` | `cdp-check.mjs` | 截圖併入 CDP 流程（同一支腳本先判定再截圖） |
| `card-check.py` | `card-pdf.py` | 後者直接產生真 PDF 並檢查頁數、A4 尺寸與文字，涵蓋前者的 DOM 檢查 |

## 四、刪除沒有用到的程式碼與樣式

- **3 個函式整段刪除**（檔內外都沒有人用）：`lib/analysis.js` 的 `skewness`、
  `public/js/charts.js` 的 `mount`、`public/js/pwa.js` 的 `onStateChange`。
- **21 個符號取消 `export`**：它們只在自己那個檔案裡用得到（例如 `lib/geo.js` 的
  `twoOpt`／`pathLength`、`lib/repo.js` 的 `photoPublicUrl`）。對外暴露沒有用途的 API，
  會讓人以為別處在用、不敢改。
- **7 條沒用到的 CSS 規則刪除**：`.grid-3`、`.center`、`.right`、`.skeleton`＋`@keyframes shimmer`、
  `.summary.note`、`.card-cols`、`.card-check-grid`、列印時要隱藏的 `.site-banner`／`.db-banner`。
  刪除前逐條以「類別字串是否真的出現在 HTML／JS」核對——**`notice-*`、`badge-*` 這類由樣板動態拼出來的家族一律保留**
  （`class="notice-${tone}"` 這種寫法用純字串搜尋會誤判成沒用到）。

## 六、新增守門測試：`tests/repo-hygiene.test.js`（5 項）

讓「這次清掉的東西」不會悄悄長回來：

1. 版控不得有瀏覽器設定檔（`prof-*`）、稽核暫存頁（`public/__*.html`）、日誌、系統檔。
2. 版控不得有單檔 > 1.5 MB（產生器產物或誤放的二進位檔）。
3. `scripts/` 不得有孤兒腳本（沒有任何地方引用）。
4. `scripts/` 每個檔案都要出現在 README 的腳本表裡。
5. `.gitignore` 必須持續擋住 `node_modules/`、`.env`、`prof-*/`、`*.log`。
