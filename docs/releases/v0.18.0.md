# v0.18.0 — 數學科報告（Word）產生流程

本版沒有改動網站功能，改的是「報告怎麼產生」。學期作業的數學科部分（分析 E：用數學模型擬合冠幅與樹高的關係）
需要一份 Word 報告；如果數字是手抄的，之後官方資料更新就沒人知道那些數字還對不對。
因此這一版把報告變成**可以重跑的程式**：讀同一份官方資料、用自己實作的統計函式計算、畫圖、組裝成 `.docx`。

## 新增

- **`scripts/report_stats.py`**（統計核心，純標準庫）
  - 自實作 t、F、χ²、常態分布函式（t／F 用不完全貝他函數、χ² 用不完全伽瑪函數的連分數展開），
    不用 numpy／scipy——這樣報告裡每一個 p 值都指得出是哪一段程式算的。
  - 敘述統計、皮爾森／斯皮爾曼相關與 t 檢定、最小平方迴歸（含高斯消去解正規方程）、
    單因子 ANOVA（含 η²／ω²）、卡方獨立性檢定（含 Cramér's V 與最小期望次數檢查）、Welch 兩樣本 t 檢定。
- **`scripts/report-charts.mjs`**（圖表產生器）：以專案本來就用的 Chart.js ＋ 無頭 Chrome 畫六張圖
  （樹齡直方圖、樹齡～樹高散點＋最佳模型、樹高～冠幅散點＋線性／二次、前 10 樹種平均樹高與 95% 信賴區間、
  2026–2076 存活投影、胸圍～胸徑的 π 檢驗）。信賴區間用一個小外掛畫誤差線。
- **`scripts/report-math.py`**（報告產生器）：讀 `data/snapshot.json`（官方值優先）→ 計算 → 畫圖 →
  python-docx 組裝。產出封面、12 節、17 張表、6 張圖、參考資料與兩個附錄；
  附錄 B 列出可重現指令，以及「本報告（Python）」與「網站 `lib/analysis.js`（JavaScript）」
  兩套互不引用實作的對照表。
- `npm run report:math`；README 新增「二十四、數學科報告（Word）」。

## 已知限制

- 報告的圖表需要 Google Chrome（無頭模式）；`.docx` 需要 `pip install python-docx`。
- 官方冠幅只有 67／658 株有值，第七節的模型只適用於這 67 株（已用 Welch 檢定確認這 67 株與其他株無系統性差異，但缺值非隨機抽樣）。
- 卡方檢定的最小期望次數低於 5（路氹填海區 × 瀕危），p 值僅供參考。
- 網站功能與 API 與 v0.17.0 相同，僅版本字串更新為 v0.18.0。
