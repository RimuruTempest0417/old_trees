# v1.0.2 — 桌機頁首改成兩欄：標題與說明同一列，右側空間不再空著

這一版只有一個改動，來自你的回覆：「手機保持現在的方案，電腦調整換行令到右側空間不被浪費」。

## 改什麼

`.page-head` 在 **901px 以上**改成兩欄格線：

- 左欄固定 `15rem`：頁面標題（總覽／地圖查詢／優先保育名單…）。
- 右欄 `1fr`：說明文字（原本在標題下方另起一行）。
- `align-items: baseline`，標題與說明的第一行文字對齊。

效果：整張標題卡橫向被填滿、也少一行高度；**901px 以下（含手機）維持原本上下堆疊的版本**，
手機的版面完全沒有改變。

## 實測

| 項目 | 量測 | 結果 |
|---|---|---|
| 1440px、9 個分頁 | 說明文字右緣 vs 卡片內緣 | 1163–1357px vs 1363px → 右側只剩 6–14px 的正常換行餘量 |
| 1440px 改前 | 說明只佔左半 | 右半整片空白（就是你說的那個浪費） |
| 390px | `.page-head` display | `block`（上下堆疊，不變） |
| 900px | 同上 | `block`（斷點下緣維持堆疊） |
| 1024px | 同上 | `grid`（兩欄生效） |

## 測試

- `npm test`：**26 組、376 項全過**（新增一項守門：901px 以上必須是兩欄、手機不受影響）。
- `npm run check`：**93 個檔案**通過。
- `node scripts/build-sw.mjs`：預載 60 項、版本 `v1.0.2`。
