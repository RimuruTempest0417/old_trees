# v0.6.8 — 每株古樹一個二維碼（QR 碼分頁＋詳情面板掛牌）

## 一、新增功能

### 1. 新的「QR 碼」分頁（第七個分頁）

為 **658 株古樹各產生一個二維碼**，掃描後在手機直接開啟：

- **古樹詳情**（`#/map?tree=<編號>`）——預設，適合做樹上掛牌、導覽；
- **實地考察表單**（`#/field?tree=<編號>`）——表單會自動帶入古樹編號，適合班級分派考察任務。

分頁功能：

| 控制項 | 說明 |
| --- | --- |
| 掃描後開啟 | 古樹詳情／實地考察表單 |
| 堂區 | 8 個堂區（也顯示全部） |
| 排序 | 樹齡由高至低（預設）／編號／地點名稱 |
| 關鍵字 | 編號／樹種／地點即時篩選 |
| 數量 | 12／24／48／120／全部符合 |

- **列印標籤**：`@media print` 樣式會自動改成**三欄**、白底黑碼、去掉按鈕與陰影，
  直接把標籤印出來剪下使用。
- **下載 SVG**：單張向量圖，放大列印不失真；另有**複製連結**方便貼到群組。
- 篩選條件會寫進網址（`#/qr?parish=花王堂區&mode=field&limit=48`），可分享或存書籤。

### 2. 地圖「單株詳情」面板

新增「**顯示二維碼**」（彈窗顯示該株的碼、可複製連結／下載 SVG／列印）與
「**列印標籤**」（直接跳到 QR 分頁且只留這一株）。

## 二、實作方式

- **編碼**：`public/vendor/qrcode.js`（qrcode-generator 1.4.4，MIT，Kazuhiko Arase）。
  以 `<script>` 載入（與 Leaflet、Chart.js 相同做法，**不依賴外部 CDN**）；
  `scripts/vendor.mjs` 負責複製並自動加上來源與授權說明，已驗證**扣掉說明後與 npm 原檔逐位元相同**。
- **繪圖**：`public/js/qr.js` 自己把矩陣畫成 **SVG 單一路徑**（`shape-rendering="crispEdges"`，列印不模糊），
  並帶 `role="img"`／`aria-label`／`<title>` 無障礙屬性。
- **糾錯等級 M**（約可容忍 15% 污損），適合貼在戶外樹上。
- 產生的連結一律是**絕對網址**——掃描的人多半在手機、與產生的人不同裝置。

## 三、驗證

### 1. 單元測試 `tests/qr.test.js`（11 項）

以瀏覽器相同的方式載入第三方程式庫後檢查：

- 尺寸符合標準（21＋4k）且內容變長時版本會提高；
- **三個定位圖案**（7×7 含中心 3×3）逐格比對、與資料區之間有淺色分隔；
- **時序圖案**深淺交替；
- 同一輸入結果具決定性、不同古樹產生不同碼；
- 資料量過大時**明確報錯**而不是產生壞碼；
- URL 產生器（絕對網址、未知模式回退、特殊字元編碼）、`siteBase` 由任意頁面網址推出根目錄；
- SVG 格式（靜區、`crispEdges`、無障礙屬性、深色模組數與路徑數一致）與下載檔格式（`xmlns`、XML 宣告）；
- **658 株全部實際試算一次**。

### 2. 獨立解碼驗證「真的掃得出來」（`npm run qr:verify`）

矩陣結構正確 ≠ 手機掃得出來，所以另外用**與本專案無關的實作**驗證：

```bash
node scripts/qr-roundtrip.mjs      # 產生 SVG → 無頭 Chrome 轉 PNG（.qr-check/）
python3 scripts/qr-decode.py .qr-check   # OpenCV QRCodeDetector 解碼並比對原文
```

取樣：固定編號 66、最老的一株、官方照片已下架的一株（471）、編號最大的一株，
每株各做「詳情」與「實地考察」兩種碼 → **全部解出的文字與原始網址完全相同**。

### 3. 無頭瀏覽器實測 QR 分頁

- `#/qr?tree=66` 深連結只產生 **1 張**標籤、含可複製的絕對網址；
- `#/qr?limit=12&mode=field` 產生 **12 張**、連結指向實地考察表單、每張都有 SVG 與複製按鈕；
- 390px 手機寬度**無橫向溢出**；
- 頁面截圖中的二維碼再由獨立解碼器解出正確網址（見驗證報告）。

## 四、使用方式

1. 重新整理頁面 → 上方多一個「**QR 碼**」分頁。
2. 選「掃描後開啟：實地考察表單」、堂區與數量 → **產生二維碼** → **列印標籤**（A4 三欄）。
3. 手機相機對著標籤即可開啟該株頁面；地圖上的單株詳情也有「顯示二維碼」可直接出示。
