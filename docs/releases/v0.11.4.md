# v0.11.4 — 監測單株卡片補上樹齡的兩個來源

v0.11.3 讓監測序列看得到「官方樹齡更新」之後，`GET /api/monitoring?tree=<no>` 的單株資料仍只帶
`listing_grade`／`listing_health`，沒有對應的樹齡欄位 —— 這一版補齊。

## 內容

- `lib/routes/monitoring.js`：單株資料新增 `official_age_years` 與 `listing_age_years`，
  與既有的 `official_grade`／`listing_grade`、`official_health`／`listing_health` 對稱。
- `public/js/monitoring.js`：單株卡片在「官方分級」「官方健康狀況」的來源說明旁，
  補上樹齡說明 ——《古樹名錄》原本列 155 年，市政署自然網現行為 115 年 — 本平台以官方現行值為準（僅在兩者不同時顯示）。
- `tests/monitoring.test.js`：單株 payload 必須帶兩個樹齡欄位；前端必須有 `listing_age_years` 的說明。

## 驗證

- `npm run check` 通過；`npm test` 17 組 259 項全過；`ui-audit` 100/100
- 線上讀回：`GET /api/monitoring?tree=619` 的 `tree.listing_age_years = 155`、`official_age_years = 115`；
  觀測點 155 → 115 年；異常 `age_change`（info）
