# v1.0.0 — 網站正式版：修掉回報的三個問題（＋稽核抓到的兩個），每一顆按鈕都真的點過

這一版沒有加新功能。把「平台本身」做穩：修掉你回報的三個問題、補上自動化的分頁稽核
（每一顆按鈕、下拉、開關都真的點一次），並整理優先保育名單的版面。

## 你回報的三個問題

### 1. 優先保育名單下方比較混亂 → 表格重建、加上分隔

`table.table` 過去**完全沒有 CSS**（只有瀏覽器預設樣式），11 欄的內容擠成一團。現在：

- 列線、欄線、斑馬紋、表頭底色與黏性表頭。
- 「主要理由」改成清單（・逐條），配分另成一列並用虛線分隔。
- 「建議行動」每一條之間加分隔線與間距，時程徽章與說明分行，不再與下一條黏在一起。
- **手機（≤700px）改成一株一張卡**：用 `data-label` 當欄位名（名次／古樹／樹種／樹齡／
  健康（官方）／分級（官方）／胸徑／區位風險／分數／主要理由／建議行動），不必左右滑動。
  桌面版不受影響。

### 2. 數據分析切換線條沒有變化 → Chart.js 重複建立

`public/js/charts.js` 每個圖表建構函式都直接 `new Chart(canvas)`。Chart.js 不允許同一塊 canvas
同時掛兩張圖，第二次以後會丟出「Canvas is already in use」而保留舊圖 ——
畫面看起來就是「切了模型，曲線沒動」。

修法：新增 `mount()`，建立新圖表前先 `destroy()` 同一塊 canvas 上的舊圖，
`barChart`／`stackedBar`／`doughnut`／`scatterWithFit`／`lineChart` 全部走這條路。

### 3. 樹木資訊面板切換頁面後不會自動關閉 → 換頁時關閉面板

面板掛在共用的 `#modal` 上，換頁時沒有人去關它（「優先保育」開的樹木卡片會留在「列印」頁）。
修法：`showView()` 一進場就 `closeModal()`，任何分頁切換都會收掉面板。

## 稽核另外抓到的兩個問題（你沒回報，但確實會發生）

### 4. 地圖：從「指定單株」的網址進來後再按套用篩選，會丟 TypeError

`TypeError: Cannot use 'in' operator to search for '_leaflet_id' in undefined`。
原因：`markercluster` 的 `zoomToShowLayer()` 會在分群圖層註冊 `moveend`／`animationend` 回呼；
使用者接著按「套用篩選」，我們 `clearLayers()` 重新加入標記，那些回呼便拿到已被移除的標記。

修法：不再用 `zoomToShowLayer()`，改成自己 `setView` 到 17 級（此級叢集已展開）再開泡泡
（`map.js` 的 `openMarker()`），並關閉分群動畫（`animate: false`）。地圖操作行為不變。

### 5. 文字換行：長網址與篩選表單把容器撐破

版面稽核（1440／1024／768／430／390 五種寬度）量到兩類溢出：

- 篩選表單的兩欄格線：`minmax(320px, 1fr)` 在容器比「320px×2＋間距」窄一點時整排溢出
  （地圖／路綫頁各 30px）→ 改成 `minmax(min(320px, 100%), 1fr)`，欄寬永遠不超過容器。
- 檔案卡的照片來源圖說：一行長網址溢出 **97px** → 對 `figcaption`、`.src-link`、`.muted`、
  `.tiny` 等加上 `overflow-wrap: anywhere`（只在真的放不下時才斷行）。

## 新增：分頁稽核（自動化「全部按鈕測一次」）

`scripts/page-audit.mjs`：

- **互動稽核**：16 個網址（12 分頁＋深連結）逐一把 `button`、`[role=button]`、`summary`、
  `a.btn`、`.tab`、`select`、checkbox／radio 點一次；每個元素都在重新載入的乾淨頁面上點，
  錯誤可明確歸屬。
- **判定**：有反應（hash／面板／toast／列印／下載／剪貼簿／內容更新／勾選／展開／選取）／
  沒反應／報錯。指紋同時包含圖表資料集、表單狀態、`<details>` 開合與 `.active` 選取狀態，
  否則「曲線換了」「勾了勾選框」「換了路綫卡片」都會被誤判成沒反應。
- **不誤報**：分成「預期無變化」（重按目前已選取的分頁／項目、必填未填被瀏覽器擋下、
  重新產生相同內容）與真正「沒反應」兩類；真的沒反應的會自動重載再點一次確認。
- **時間上限**：`--budget <秒>`，逾時就停下來並在報告註明哪一段沒跑完，不會無聲卡住。
- **版面稽核**：12 分頁 × 5 種寬度（1440／1024／768／430／390）掃描文字溢出與整頁橫向捲動。
- **不會下載到你的電腦**：CDP 下載設為 `deny`，`print`／`open`／`clipboard`／`createObjectURL`
  都被替換成計數器，只記錄「有沒有被呼叫」。

另在 `scripts/cdp-check.mjs` 加上 `--waitjs`：等自訂條件成立才截圖
（之前用 iframe 量手機寬度時常常拍到「載入中」那一格）。
