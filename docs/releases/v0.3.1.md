# v0.3.1 — 安全性修正、總覽頁統計卡重整

## 🔴 安全性（請務必處理）

- **修正憑證外洩**：`.env.example` 曾被填入真實的 Supabase 專案網址與金鑰，並隨公開倉庫發布。本次已將該檔案改回純佔位符。
- **請立即輪換金鑰**：至 Supabase Dashboard → Project Settings → API 重新產生 `anon` 與 `service_role` 金鑰（或 Rotate JWT secret），再同步更新 Vercel 的環境變數。外洩過的 `service_role` 金鑰可完整讀寫資料庫，輪換後即失效；未輪換前，任何看過該檔案的人都還能存取。
- 新增機密掃描測試 `tests/secrets.test.js`：掃描所有 git 追蹤的檔案，一旦出現 JWT 形式的金鑰或真實的 Supabase 專案網址，測試即失敗。

## 🐞 修正

- 總覽頁移除「資料來源」統計卡（原本顯示 Supabase／示範模式等系統內部資訊），該資訊不屬於報告內容。
- 「最多古樹堂區」併入「古樹總株數」卡片的說明文字；統計卡由 8 張改為 6 張，寬螢幕剛好排成一列，不再出現落單的空卡片。
- 總覽頁對 API 回傳的 `site` 區塊加上防護，欄位缺失時不再讓整頁渲染失敗。
- 環境變數若仍是 `.env.example` 的佔位符（或非 https、非法網址），一律視為「未設定」並改走內建快照；修正原本每個 API 都要等 DNS 逾時後回 500、全站形同壞掉的問題。

## 🎨 介面

- 以卡通森林插畫（pngtree-cartoon-forest-background）作為全站背景，套用 `filter: blur(8px)` 模糊效果。
- 背景上疊加紙色閱讀遮罩（亮色 68%、深色 82%），並加深 `--ink-mute` 次要文字色，確保文字對比與閱讀清晰度。
- 頁首與頁尾改為半透明加 `backdrop-filter`，與背景融合。
