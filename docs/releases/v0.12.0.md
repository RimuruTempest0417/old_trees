# v0.12.0 — 化學視角：官方環境監測數據 ＋ 化學機制（作業要求 F）

這一版把作業第 3 點 **F「針對 A–D 選一點做化學視角分析補充」** 做進網站：新增
**「化學視角」分頁**（第 11 個分頁），把澳門官方的空氣與降雨監測數據、以及酸雨／土壤酸鹼／
水泥鋪面影響樹木的化學機制，和本站的古樹資料放在一起看。

實地考察仍待現場完成，因此本版**不依賴任何實地數據**——全部用官方公開數據與可查證文獻。

## 二、新增分頁「化學視角」（`#/chemistry`）

- **六張 KPI 卡**：PM10 36.1、PM2.5 17.3、NO₂ 29.3、O₃ 55.6、SO₂ 4.4 µg/m³、CO 0.6 mg/m³（2025 年官方年均），
  附官方年平均標準、**達標百分比**與**與 2024 年的變化**。
- **圖表**：各站 PM2.5 年均（含標準值）、六種污染物 2024／2025 對照、荷蘭園站 2006–2025「不良」日數趨勢。
- **表**：各站污染物年均矩陣（超過標準者標紅）＋ 監測站特徵與 **2025 年 6 月 19 日的改名對照**。
- **空氣質量水平日數**：2025 年六站日數、「良好＋普通」佔比、全年最高指數與污染物（六站皆為 PM10、4 月 13 日沙塵事件）。
- **降雨酸鹼度**：官方歷史值、pH 5.6／5.0 的判定說明，以及「2000 年後官方公開年值查不到」的明示。
- **化學機制卡（附化學式與出處）**：
  - 酸雨形成 `SO₂ + H₂O ⇌ H₂SO₃`、`2 SO₂ + O₂ + 2 H₂O → 2 H₂SO₄`、`4 NO₂ + O₂ + 2 H₂O → 4 HNO₃`
  - 鹽基淋溶 `2 H⁺ + 土壤膠體–Ca²⁺ → 土壤膠體–H₂ + Ca²⁺`；pH < 5.5 鋁溶出 `Al(OH)₃ + 3 H⁺ → Al³⁺ + 3 H₂O`
  - 水泥微環境 `水泥水化 → Ca(OH)₂（pH 12–13）`、`Ca(OH)₂ + CO₂ → CaCO₃ + H₂O`、`CaCO₃ + 2 H⁺ → Ca²⁺ + H₂O + CO₂↑`
  - 碳酸鹽緩衝 `CaCO₃ + H₂CO₃ → Ca(HCO₃)₂`
- **古樹 × 區域對照**：澳門半島／路環／氹仔三區的官方健康狀況、**平均樹齡**、該區官方監測站 PM2.5／NO₂，
  並明示「**相關不等於因果**」。
- **「本頁沒有的東西」卡**：清楚列出沒有官方逐點土壤理化數據、沒有逐點礦物成分數據、沒有實地採樣。

## 三、單株詳情新增「環境背景（化學視角）」

每一株古樹的詳情面板多一段：顯示該株所在**區域**官方監測站的 2025 年年均值（PM2.5、NO₂）、
資料內容雜湊，並寫明「這是該區域的空氣背景值，**不是這一株古樹的實測值**」，附往化學視角分頁的連結。

## 四、科普第 12 篇

〈**化學視角：酸雨、土壤酸鹼與水泥如何影響澳門古樹**〉（分類「化學視角」，9 筆來源）：
官方監測到的酸雨、從雨滴到根的化學路徑、水泥與鋪面的鹼性微環境、土壤 pH 與養分有效性對照表、
可以把化學變成行動的三件事（不要把水泥貼到樹基／監測要延續／注意臭氧這類二次污染物）。

## 五、工程改進（順手修掉的問題）

1. **`scripts/cdp-check.mjs`（新）**：以 Chrome DevTools Protocol 驗證「跑完 JavaScript 之後」的頁面，
   等到指定字串真的出現才輸出，並印出 console 錯誤與未捕捉例外。
   *為什麼要加*：本版第一次驗證 `#/chemistry` 時，`--dump-dom` 把「載入中的錯誤卡」當成結果放過，
   實際上頁面有一個 TypeError（前端把 API 回應路徑寫成 `d.air`，正確是 `d.doc.air`）——
   改用 CDP 之後這個錯誤立刻現形。
2. **`scripts/gen-init-sql.mjs`（新）**：`supabase/init.sql` 以前是手工拼出來的，改版後常常忘記重拼，
   於是「使用者要貼進 SQL Editor 的那個檔」會落後好幾版。現在由 `npm run build:data` 一併產生，
   測試會以 `--check` 擋住落後的情況。
3. **`scripts/gen_upgrade_sql.py` 改為自動推導 CHECK 允許值**：以前允許值清單是手抄的，
   新增分類（本次的「化學視角」）就會忘記同步，導致舊資料庫升級後 seed 被 `23514` 擋住；
   現在直接從 `schema.sql` 的 `check (… in (…))` 推導，並自動產生「先正規化、再移除、再重建」的升級段。
4. **官方年均值一律顯示到小數第一位**：修正前把 PM2.5 的 17.3 印成「17」、年份印成「2,025」；
   現已統一為一位小數，並加測試鎖住（KPI、矩陣表、區域表、單株詳情）。
5. **`init.sql` 的 CHECK 允許值**已含「化學視角」分類，使用者重跑 `supabase/init.sql` 即可入庫新文章。
