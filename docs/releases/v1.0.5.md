# v1.0.5 — 監測與政策方案頁面：把元素分散一點

你回報「監察和政策方案頁面的元素太密集了」。量出來有兩個原因，都不是字太小，而是**間距本來就是 0**。

## 量到的兩個原因

| 原因 | 實測 |
|---|---|
| 區塊「上下相黏」 | 監測頁：頁首下方有 19.2px，但 **KPI 區與三張卡片的 margin-bottom 都是 0px**；政策方案頁：一般卡片也是 0px，只有方向區塊有 16px |
| 監測頁的 KPI 卡沒有排成格線 | `.kpi-grid` 沒有任何 `display` 規則，5 張 KPI 卡直直疊成一欄，整區 **623px 高** |

## 改什麼（只影響這兩頁）

- **區塊間距**：兩頁的所有區塊改成 `margin-top: 1.75rem`（28px）
- **卡片內距**：17.6×19.2px → **22.4×24px**
- **標題上下留白**：`h3` 加上方 1.15rem、下方 0.85rem；`h2` 下方 1rem
- **段落之間**：卡片內的連續段落 `p + p` 加上 0.8rem
- **清單項目**：`li + li` 加上 0.4rem
- **表格格內距**：6.72×8.8px → **9.92×11.52px**（政策依據表、監測表格更好讀）
- **行動卡的值列**：`.kv` 4.48px → 6.45px
- **行動卡之間**：`.policy-actions` 間距 0.8rem → **1.3rem**
- **監測頁 KPI 區**：補上 `display: grid`＋`repeat(auto-fit, minmax(210px, 1fr))`，5 張卡排成一列

字級、欄寬、顏色都沒有動。

## 實測

| 項目 | 改前 | 改後 |
|---|---|---|
| 監測頁區塊間距 | **0px** | **28px** |
| 監測頁 KPI 區 | 623px（直疊一欄） | **161px（5 欄一列）** |
| 政策方案區塊間距 | 16px／0px | **28px** |
| 卡片內距 | 17.6×19.2px | **22.4×24px** |
| 表格格內距 | 6.72×8.8px | **9.92×11.52px** |

- 手機 390px：KPI 自動變 **2 欄**、區塊間距 28px、橫向溢出 **0px**。
- 其他分頁不受影響：總覽與優先保育的卡片內距仍是 17.6×19.2px。
- 版面稽核（12 分頁 × 5 寬度）：**✅ 全部通過**（無溢出、無裁切、文字排版 0 處、可點元件 ≥28px）。
- 介面稽核 `ui-audit.sh`：**120 / 120**。
- A4 列印頁面逐項不變：檔案卡 1 頁／804 字、考察單 1 頁、政策摘要 9 頁／12,784 字、
  行動清單 4 頁／4,406 字、路綫冊 11 頁／3,148 字。
- `npm test`：28 組、**384 項全過**（`tests/ui.test.js` 新增 1 項守門：這兩頁的間距規則不得被刪）。
- `npm run check`：94 個檔案通過；`build-sw.mjs`：60 項、版本 `v1.0.5`。

## 如果還要更鬆

現在是 28px 的區塊間距與 22.4×24px 的卡片內距。要更鬆（例如 36px／1.6rem 內距）或更緊一點，
說一聲就好——這個值集中在同一段 CSS，改一個數字就生效。
