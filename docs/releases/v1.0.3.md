# v1.0.3 — 列印修正：紙上的樣子（政策方案印出來不再是細長條）

你回報的「政策方案那一版的排版和文字都有問題」，把那份 PDF 拆開來看之後找到真正的原因——
問題不在螢幕上，而是**列印時**才出現，所以網頁看起來一切正常。

## 那份 PDF 長什麼樣

你存下來的檔案（`政策方案｜澳門古樹保育研究平台.pdf`）實測是：

- **1 頁、402 × 14400pt** —— 約 142mm 寬、5 公尺長的「一張超長紙」，不是 A4 分頁。
- 表格與說明被壓成細長條，一個詞一行。
- 導覽列在右邊被切掉。

## 真正的原因（兩個）

**① `print.css` 寫死了「只印 A4 列印分頁」**

原本有一條規則：`main > section.view:not(#view-card) { display: none !important; }`。
它的用意是「列印時只印 A4 頁面本身」，但那是給 `#/card?mode=…` 這些列印分頁用的；
在政策方案、優先保育等分頁按 ⌘P 時，其他分頁本來就帶 `hidden` 屬性、根本不會顯示，
於是整份文件變成**沒有任何可見內容** → 得到一張完全空白的 A4
（實測：595 × 842pt、文字 0 字）。

**② 列印寬度只有 A4（約 793px），但版面還是螢幕上的多欄格線**

- 行動卡用 `repeat(auto-fit, minmax(320px, 1fr))`：在 793px 下每欄只剩約 260px，
  中文每行兩三個字就斷行（你看到的一條條細長條）。
- `style.css` 的 `@media print { .card { page-break-inside: avoid } }`：
  整張「政策依據」表放不進剩下的版面時，會整張跳到下一頁，紙上出現大片空白。
- 深色模式直接印會整張黑（變數是深底淺字），又吃碳粉。

## 修法

| 問題 | 修法 |
|---|---|
| 只印列印分頁 → 空白紙 | 改成只隱藏帶 `hidden` 的分頁（也就是只印「目前顯示」的那一頁） |
| 深色模式印出整張黑 | 列印時把色彩變數覆蓋回淺色（`--card: #fff`、`color-scheme: light`） |
| 三欄格線在 A4 被壓成細長條 | 列印時多欄一律收成單欄；統計數字卡四欄、照片與 QR 兩欄 |
| 空篩選框印出一堆標籤 | 列印時隱藏篩選欄位，只留下「符合條件 50 株／共 658 株」 |
| 大容器不跨頁 → 大片空白 | 卡片與表格允許跨頁；表頭每頁重印、單列不切斷 |
| 標籤／數值表被擠成細條 | 列印時固定欄寬（標籤 15%／數值 85%） |

**A4 列印分頁（`#/card?mode=…`、行動清單、路綫冊）的規則完全沒動**，
每一張的頁數與文字量都與 v1.0.2 逐項相同（見下表），沒有連帶影響。

## 工具：`cdp-check.mjs --pdf`

`scripts/cdp-check.mjs` 新增 `--pdf <路徑>`，用瀏覽器自己的列印引擎（CDP `Page.printToPDF`
＋`preferCSSPageSize`）輸出 PDF，驗完就能讀回頁數、紙張尺寸與文字量——
以後「紙上的樣子」可以一鍵重驗，不用手動存 PDF。

**驗證時一定要等內容渲染完**（`--waitjs`）：沒有等就會在 JS 畫完之前輸出，得到 0 字的空白 PDF。
