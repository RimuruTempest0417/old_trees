# v0.5.0 — 深淺色模式與手機瀏覽器適配

網站本來只為「桌面 ＋ 淺色」設計：深色模式只覆蓋了一部分色票，手機上幾乎沒有斷點。
這一版把兩件事補齊，並修掉自動化稽核實際在手機寬度上抓到的版面破損。

## 一、跟隨系統深淺色

- 以 `@media (prefers-color-scheme: dark)` 覆寫**全套色票變數**，不是逐條改顏色，
  所以新增元件只要用變數就會自動支援深色。
- `:root { color-scheme: light dark }`：下拉選單、捲軸、日期選擇器、autofill 等**原生控件**
  跟著系統變色（這部分無法用 CSS 自訂）。
- `<meta name="theme-color">` 淺色 `#14532d`／深色 `#101613` 兩版，手機瀏覽器的介面帶
  也會跟著變，不會出現深色頁配亮綠色橫條。
- 深色下的細節：表頭改為不透明底色（捲動時資料列不會從底下透出）、模態遮罩加深、
  `::selection` 反白。
- **Leaflet 地圖**的內建樣式是為淺色底設計的，另外覆蓋彈窗、縮放鈕、比例尺與授權列；
  圖磚以 `invert(1) hue-rotate(180deg)` 反相，深夜瀏覽不刺眼。
- 連結色在深色模式另設 `--link`（深綠 `#166534` 在深底上對比不足）。

## 二、手機瀏覽器

| 項目 | 做法 |
| --- | --- |
| 瀏海與底部指示列 | `viewport-fit=cover` ＋ `env(safe-area-inset-bottom)` |
| 網址列造成的高度跳動 | `dvh` 取代 `vh`（地圖、彈窗、清單高度） |
| iOS 橫向自動放大字級 | `-webkit-text-size-adjust: 100%` |
| iOS 聚焦輸入框自動放大整頁 | 輸入框在 ≤940 px 一律 16 px |
| 觸控目標 | 按鈕 44 px、標籤 40 px、頁籤 40 px；`touch-action: manipulation` 消除點擊延遲與高亮方塊 |
| 窄螢幕排版 | 斷點 940 / 700 / 400 px：統計卡 2 欄、圖表縮高、**地圖移到最上方**、頁籤列改為橫向滑動（不擠成兩行）、單株詳情改為**底部浮出**的面板 |
| 寬表格 | 由 `.table-wrap` 自己橫向捲動，**不用 `overflow-x: hidden`**（會破壞 sticky 頁首） |
| 列印 | 不輸出模糊森林背景，隱藏頁首頁尾與按鈕，回到白底黑字 |

## 三、稽核實際抓到的三個 bug（已修）

1. **手機版面橫向溢出 18 px（360 px 螢幕、分析頁）**
   根因是 CSS Grid 的老陷阱：格線項目預設 `min-width: auto`，等於「不得小於內容最小寬度」，
   卡片被裡面的寬表格撐到 364 px、超出 332.8 px 的格線。改為
   `minmax(0, 1fr)` ＋ `.grid > *, .split > *, .map-layout > * { min-width: 0 }`，
   內部寬表格改由 `.table-wrap` 捲動。
2. **輸入框 16 px 的規則被蓋掉（iOS 仍會自動放大）**
   `input[type="text"]` 的屬性選擇器權重高於 `input`，而基礎樣式的 `.92rem`（14.72 px）
   因此勝出。改為以**同權重選擇器**逐一覆寫（並在測試中斷言「基礎樣式的每一種 input 型別
   都必須被覆蓋」，避免以後新增型別又漏掉）。
3. **平板上的按鈕只有 34 px**
   觸控目標規則原本只寫在 ≤700 px 斷點，iPad（768–1024 px）拿不到；提升到 ≤940 px。

## 四、新增的自動化稽核

- **`scripts/ui-audit.sh <port>`**：以無頭 Chrome 在 **360／390／414／834／1440 px**
  與**深淺色**共 50 組組合下量測：頁面橫向溢出、元素溢出（排除可捲動容器與地圖圖磚緩衝區）、
  觸控目標高度、文字輸入框字級、統計卡欄數、地圖是否排到最前、頁籤是否改為橫向滑動。
  有問題時離開碼為 1。
  因為無頭 Chrome 的視窗寬度下限約 500 px，量測改在**同源 iframe**內進行，寬度才真正可控。
- **`tests/ui.test.js`（13 項）**：把上述規則寫成回歸測試，誤刪時會直接失敗，
  例如禁止 `overflow-x: hidden`、禁止 `grid-template-columns: 1fr`（未加 `minmax` 無法被壓縮）、
  深色模式必須有 Leaflet 覆蓋、`viewport-fit=cover`、`color-scheme`、CSS 大括號成對。

實測結果：**50 組全部 `pageOverflow = 0`、觸控目標 ≥40 px、輸入框字級 ≥16 px**。
